# 📊 Sales Analysis Dashboard (Power BI)

This project presents an **interactive Power BI dashboard** built to evaluate sales performance across product categories, customer segments, payment preferences, and regional distribution.  
It helps businesses track revenue, understand buying behavior, identify top categories, and measure performance impact visually through dynamic insights & filters.

---

## 🚀 Key Business Metrics

| Metric | Value |
|--------|-------|
| 💰 **Total Sales** | 322.97K |
| 📦 **Quantity Sold** | 6,000+ |
| 🧾 **Total Tax Generated** | 15.38K |
| 🔹 **Avg Unit Price** | 55.67K |

## 📊 Dashboard Overview — What This Reveals

- 📦 Product-wise Sales & Comparison  
- 🌍 City-wise Revenue with Customer Type Split  
- 💳 Mode of Payment Distribution  
- 👨‍💼 Gender-wise Sales Comparison  
- 🥇 Top Performing Product Categories  
- 🔄 Dynamic Filtering using Slicers  
  **(Product Line | Payment Type | Branch | Customer Type)**

## 📌 Key Insights Identified

📍 "Food and Beverages" ranks highest in revenue contribution  
📍 Majority of customers use **E-Wallet & Credit Card** for payments  
📍 Female buyers hold slightly higher purchase share vs Male  
📍 Yangon & Naypyitaw drive higher revenue compared to Mandalay  
📍 Product categories show balanced contribution with visible outliers
